# Meeting Recall Icon Assets

This folder holds app icon assets.

Current files:
- `app-icon.png`: 1024 x 1024 iOS/general app icon export with dark background, white radiant mark, red recording dot, and dark red halo
- `app-icon-500.png`: 500 x 500 reference export matching the approved visual direction
- `adaptive-icon-foreground.png`: 1024 x 1024 transparent Android adaptive icon foreground with white radiant mark, red recording dot, and dark red halo

Android adaptive icon background color is configured as `#202020` in `app.json`.

Before store submission, verify both assets on real devices for small-size readability and Android mask cropping.

Avoid:
- full wordmarks
- busy gradients
- generic AI imagery
