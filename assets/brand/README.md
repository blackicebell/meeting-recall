# Meeting Recall Brand Assets

This folder holds brand-level assets such as the primary mark, wordmark, and social preview artwork.

Current source assets:
- `logo-primary.svg`: full Meeting Recall logo lockup
- `logo-mark.svg`: standalone Meeting Recall mark
- `logo-primary.png`: app-ready raster export of the provided mark
- `logo-mark.png`: app-ready raster export of the provided standalone mark
- `logo-primary-transparent.png`: white-background-friendly mark used inside the app

The app icon and splash exports are generated from the provided source artwork and kept in `/assets/icons` and `/assets/splash`.

Visual direction:
- clean recorder mark
- premium and minimal
- primary blue #4b7de6
- recording red only as an accent
- avoid generic AI symbolism
