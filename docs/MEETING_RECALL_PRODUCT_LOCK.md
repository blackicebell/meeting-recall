# Meeting Recall Product Lock

## Product Definition

Meeting Recall is a local-first mobile app for recording meetings and making those recordings easy to use with Google NotebookLM.

## Core Promise

Record meetings. Save them clearly. Open NotebookLM. Get insights there.

## Primary User

People who attend a lot of meetings and want a simple way to capture conversations without paying for expensive AI meeting tools.

## Emotional Problem

Users leave meetings forgetting important details, decisions, and action items. Meeting Recall gives them confidence that nothing important is lost.

## The App Does

* Record meeting audio
* Save recordings locally
* Name recordings by date and meeting title
* Sync with Google Calendar for meeting names
* Play recordings back
* Rename recordings
* Save files to a visible “Meeting Recall” folder
* Make recordings easy to find when uploading to NotebookLM
* Open NotebookLM as the main handoff action

## The App Does Not Do

* No in-app AI summaries
* No transcription
* No cloud storage
* No team collaboration
* No automatic NotebookLM upload
* No complex dashboard
* No bookmarks or timestamp features

## Main UX Rule

The user should never wonder where the recording is or what to do next.

## Primary CTA

Open NotebookLM

## Secondary CTA

Share

## Most Important Flow

Old recording → Open NotebookLM → User finds file easily → Uploads to NotebookLM

## Product Philosophy

Meeting Recall is intentionally focused and minimal.
The app should feel calm, premium, and obvious to use.
The experience should reduce thinking and decision-making.
NotebookLM is not a secondary feature — it is the core workflow.

## Visual Direction

* Light-only
* Clean
* Minimal
* Typography-led
* Primary blue: #4b7de6
* Red only for active recording
* Dividers over cards
* Gradient only for the most important CTA

## File Naming Rule

All recordings should use:
YYYY-MM-DD – Meeting Name.m4a

Example:
2026-04-29 – Meeting Yoshi.m4a

## Critical Technical Expectations

* Recordings must save to a user-accessible “Meeting Recall” folder
* Renaming a recording must rename the actual file on the device
* Files should appear in Recents when users upload to NotebookLM
* Open NotebookLM should be easier to access than Share
* The app should minimize friction between recording and AI insight generation

## Success Definition

A non-technical user can:

1. Record a meeting
2. Save it
3. Open NotebookLM
4. Immediately find the file
5. Upload it without confusion
