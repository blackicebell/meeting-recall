# Meeting Recall App Store Launch Checklist

## Purpose

This document defines everything required before Meeting Recall can launch publicly on the Apple App Store and Google Play Store.

The goal is to ensure:
- app approval readiness
- product clarity
- branding consistency
- launch preparedness
- user trust
- smooth onboarding

This checklist should be completed before submission.

---

# 1. Product Readiness

## Core Functionality
- Recording works reliably
- Playback works reliably
- Files save locally
- Meeting Recall folder accessible
- Rename updates actual file name
- Open NotebookLM flow works
- Old recording flow works
- Permissions handled correctly
- Calendar integration works
- Error states handled gracefully

---

# UX Quality
- UI visually consistent
- Typography hierarchy polished
- Spacing consistent
- Recording screen feels focused
- Open NotebookLM clearly primary CTA
- Share visually secondary
- Empty states complete
- Error states complete

---

# Performance
- Fast app launch
- Smooth scrolling
- No major frame drops
- Long recordings stable
- No major memory leaks
- No crashing during core flows

# 15. Final Launch QA

Before launch:
- Test full recording flow
- Test old recording flow
- Test NotebookLM handoff
- Test file accessibility
- Test rename behavior
- Test permissions
- Test offline recording
- Test app restart persistence

---

# Launch Blockers

Do NOT launch if:
- recordings can be lost
- files are difficult to find
- NotebookLM flow is confusing
- rename breaks file system behavior
- app crashes during recording
- onboarding confuses users

---

# Final Launch Success Definition

Meeting Recall is ready to launch when a non-technical user can:

1. Download the app
2. Understand the purpose immediately
3. Record a meeting
4. Save it
5. Return later
6. Open NotebookLM
7. Find the correct file
8. Upload it without confusion
9. Get insights successfully

without needing support or explanation.
