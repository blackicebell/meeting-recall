# Meeting Recall Screenshot Overlay Plan

## Purpose

This document defines the revised App Store and Google Play screenshot overlay direction for Meeting Recall.

The goal is to make screenshots feel:
- premium
- calm
- modern
- trustworthy
- easy to scan at thumbnail size

---

# Output Location

Final Android screenshot designs live in:

/marketing/app-store-screenshots/final/android

Raw Android screenshots live in:

/marketing/app-store-screenshots/raw/android

Raw screenshots should not be overwritten.

---

# Revised Visual Direction

The final screenshots use:
- soft blue-to-white branded backgrounds
- subtle radial glow accents
- light audio/recording-inspired shapes
- rounded phone screenshot frames
- soft shadows behind the app screenshots
- compact Meeting Recall brand mark in the upper-left

The app screenshot remains the hero.

---

# Background System

Backgrounds should use:
- near-white base
- soft primary blue glow using #4b7de6
- very subtle red accents only where recording energy is useful
- faint radial shapes or waveform motifs

Avoid:
- dark backgrounds
- loud saturated gradients
- generic AI imagery
- visual clutter
- heavy 3D device effects

---

# Composition Rules

Each screenshot should use:
- large bold headline near the top
- short secondary subtext beneath
- consistent brand mark placement
- phone screenshot framed below the copy
- generous margins
- consistent phone scale across the set
- no text covering important UI

The visual flow should be:

Brand → headline → subtext → app screen

---

# Typography Rules

Headlines should be:
- bold
- large
- readable at thumbnail size
- split into short lines

Subtext should be:
- smaller
- quiet
- one line when possible
- never visually louder than the headline
